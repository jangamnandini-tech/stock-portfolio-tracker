
# 📈 Stock Portfolio Tracker

## 📌 About the Project
Stock Portfolio Tracker is a simple Python project that calculates the total investment value of stocks based on predefined stock prices and user-entered quantities.

## 🎯 Features
- Displays available stocks and their prices.
- Accepts stock names and quantities from the user.
- Calculates the value of each stock.
- Displays the total investment value.
- Saves portfolio details in a text file (`portfolio.txt`).

## 🛠️ Technologies Used
- Python
- Dictionaries
- User Input and Output
- Conditional Statements
- Loops
- Basic Arithmetic
- File Handling

## ▶️ How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python stock_tracker.py
```

## 📝 How to Use

1. Run the program.
2. Enter a stock symbol from the available list.
3. Enter the quantity of shares.
4. Enter `done` when you finish adding stocks.
5. View your portfolio summary and total investment.
6. Check `portfolio.txt` for the saved results.

## 📂 Project Files

- `stock_tracker.py` — Main Python program.
- `portfolio.txt` — Saved portfolio summary generated by the program.
